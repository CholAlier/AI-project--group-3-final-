# AI Project — Group 3

This repository contains the Group 3 AI project for employee attrition analysis.

Files:
- `app.py` — main application entry (if present)
- `phoenix_ml.py` — ML helper script
- `Employee Attrition Rate.ipynb` — analysis notebook

Quick setup (Windows, PowerShell):

1. Create and activate a virtual environment:

```powershell
python -m venv ven
ven\Scripts\Activate.ps1
```

2. Install dependencies:

```powershell
pip install -r requirements.txt
```

3. Run the app or notebook:

```powershell
python app.py
# or open the notebook in Jupyter
```
